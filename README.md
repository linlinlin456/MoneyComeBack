	# 本钱回笼记
 
> 一个给自己用的阅读回本统计 App —— 把读过的书按价值算成钱，看看买阅读器、买会员的钱赚回来没有。
 
数据全部存在手机本地，没有账号体系，没有社交，只做记账和算账。
 
## 功能概览
 
- **书值统计**：读过的书按定价折算成金额，和阅读成本对比，直接显示回本差额；另有书籍总数、已读完数量、平均书价等指标。
- **两种价值口径**：按定价（读完整本算整本的钱）/ 按进度（读一半算半本），随时切换。
- **两种统计范围**：只记付费书（只算微信读书里「付费会员可读」的书）/ 全部记录（所有书都按定价显示）。
- **书籍类型识别**：同步时自动区分付费会员可读、体验卡可读、按章购买、免费阅读，避免把体验卡就能免费看的书算成付费书。
- **微信读书同步**：同步书架、阅读进度、阅读时长与定价；手动改过的字段不会被同步覆盖。
- **扫码录入**：扫书背 ISBN 条码自动补全书名、作者、定价，也可手动新增。
- **成本记录**：记录阅读器、会员、实体书等支出，分类汇总并参与回本计算。
- **阅读时长统计**：按周 / 月 / 年 / 累计查看时长与阅读天数。
- **批量管理**：长按进入多选，支持全选与批量删除。
- **数据备份**：一键导出全部数据为 JSON，换手机或重装后导入恢复。
- **检查更新**：配置更新源地址后，可在 App 内检查新版本并跳转下载。

## 目录结构
 
```
lib/
├── main.dart / app.dart      # 入口与应用骨架
├── models/                   # 数据模型（书籍、成本、阅读汇总、设置、版本）
├── providers/app_state.dart  # 全局状态与同步逻辑
├── services/                 # 微信读书同步、ISBN 查询、统计、备份、检查更新
├── pages/                    # 概览、书值列表、编辑、扫码、成本、设置
├── widgets/                  # 通用组件
└── theme/                    # 主题与配色
```
 
## 运行与打包
 
```bash
flutter pub get
flutter run
 
flutter build apk --release   # 产物在 build/app/outputs/flutter-apk/app-release.apk
```
 
需要 Flutter 3.24 或更高版本，Android 端 `minSdk` 为 21（Android 5.0）。
 
## 说明
 
- 所有数据只存在手机本地的 SQLite 数据库，不上传任何服务器；除微信读书同步、ISBN 查询和检查更新外不发起网络请求。
- 微信读书相关的数据获取基于公开接口，非官方 API，接口变动可能导致同步失败。
- 本项目为个人自用工具，请勿用于商业用途。
